# 技术说明

作者：南京大学24届沈逸文  
版本：0.2.1。

## 坐标模型

普通 CameraPositionWS 对一幅视图提供统一相机位置。插件使用每个像素中心在相机近裁剪面上的世界位置作为空间判据，使跨界的像素能够选择不同区域效果。这不是可见表面位置、沿视线的积分，也不能恢复被近裁剪切掉的几何。

以左上 (0,0)、右下 (1,1) 的视口局部 UV 表示：

`P(u,v) = CameraOrigin + O + u*Dx + v*Dy`

O 是近裁剪面左上角的相机相对位置，Dx/Dy 为横向和纵向边向量。CPU 的 FCameraRefinementFrame::FromMatrices 对 UE reversed-Z 取 clip Z=1，以投影逆矩阵和视图旋转求三个角点再作差，适用于透视、正交和偏轴。像素只需仿射求值，不逐像素求逆，不读取场景深度/法线，不求射线与物体交点。

材质函数展开已有 ClipToTranslatedWorld 数据，并通过原生 LWC CameraPositionWS 加局部偏移构造世界位置。体积几何在 CPU 端先以 double 减去相机位置，再转为 GPU float，减少大世界精度损失。

## 相机配置与模块

Runtime 模块在 PostConfigInit 注册着色器目录，初始化完成后创建 SceneViewExtension。Editor 模块在 PostEngineInit 扩展 CameraActor/CameraComponent 详情和播放工具栏。生产源码不含自动化测试、演示生成命令或 AI 桥接依赖。

UCameraRefinementData 作为相机组件的 UAssetUserData 保存显式开关；不存在本地数据时读取 UCameraRefinementSettings::bDefaultEnabled。直接 CameraActor 使用自己的组件，普通 ViewOwner 查找活动相机，没有组件的默认视图使用外部设置。

通过 Post Process User Flags 的 bit 30（0x40000000）向材质传递开关，项目应预留该位，其余位保留。该标志不存体积编号。MF_RefinedCameraPosition 提供自定义输入，普通 CameraPositionWS 的全局语义保持原样。

## 官方体积原生参数栈

原生 PostProcessVolume 先在 CPU 上按单一 ViewLocation 生成整幅 FinalPostProcessSettings，单靠材质坐标函数不能改变官方白平衡等设置的边界。

插件读取 World 已排序的后处理体积列表与 GetProperties。无界和确定不跨界的体积保留在参数栈中；对需要分区的官方 brush，读取 BodySetup 的真实凸包平面、顶点和边，处理旋转、非均匀缩放及多凸包。包围盒只用于粗略剔除，不替代最终边界。

拷贝视图，以 Scene=null 的临时 Family 初始化引擎基础设置，再恢复原 Family，按原生顺序和 BlendWeight 覆盖体积参数，随后应用捕获/相机或玩家相机管理器的设置，调用 EndFinalPostprocessSettings。不会临时禁用或修改场景体积。

N 个跨界体积最多生成 2^N 个配置。第 0 个由主视图渲染，其余由瞬态 SceneCaptureComponent2D 与渲染目标完成。资源属于瞬态 UObject，不产生放置 Actor，也不写入关卡。各配置使用独立 ViewState，避免原生后处理 MID 跨配置互相覆盖。内部捕获有重入保护，不递归创建捕获。

## 分类和合成

硬边界使用凸包半空间测试，多凸包按并集分类；重叠体积的优先级和 BlendWeight 已体现在各原生配置中。Tonemap 回调以 ScreenPass 合成，分别处理主视图 viewport rect 与额外目标的归一化 UV。

平滑边界先判断内部，再计算点到有效面投影和真实网格边的最短距离，取凸包并集的最小距离。BlendRadius>=1 使用 clamp(1-distance/radius)，0<radius<1 使用原生截断形式。最终对完整原生颜色输出作多线性插值。

输出插值与逐像素重算原生参数是不同算法。非线性色彩、曝光、历史累积及跨区域卷积不能据此声称完全等价。硬边界是原生配置选择，软边界是有明确限制的近似。

## 开销、资源和回退

坐标计算不依赖背景物体数量，但额外完整场景渲染的成本取决于场景复杂度。N=1/2/3 最坏额外 1/3/7 次场景渲染，加一次合成；默认预算 8 个配置。整面需要同一套不同于相机点的参数时只修正主视图，避免额外捕获。

上限为 256 平面、32 凸包、512 边。预算、凸包接口或渲染路径不满足时保留原生输出并报告状态。XR、低于 SM5、路径追踪显式回退；邻近第三方接口缺少可读凸包时也不假装精确处理。

游戏线程通过渲染命令队列提交逐视图数据，渲染线程执行 RDG 合成。世界清理和模块关闭时注销瞬态组件、清除帧映射并等待渲染队列。适用基准为 UE 5.7.4、Win64、D3D12/SM5；分屏、其他视图扩展顺序、SM6、TSR、多 GPU 等需目标工程评估。
