# 作者标识与文件完整性

作者：南京大学24届沈逸文

作者标识不绘制到游戏画面，也不改变相机计算、材质输出和体积设置。

- C++、C#、shader、Godot 脚本、配置与文档使用各自合法的注释或元数据署名。
- UE 插件管理器的 CreatedBy 与 Godot 插件的 author 显示作者。UE 材质函数资产以原生 package metadata 保存 Author。
- 两个 UE 模块导出返回作者字符串的函数，二进制中保留作者文字；这些函数不被渲染路径调用。
- 不能任意改写主体的 DLL、LIB、OBJ、Godot UID 等文件，通过 NTFS `Author` 备用数据流标识。该元数据不会进入引擎读取的默认数据流，因此不改变文件主体和校验值。
- ZIP 的每个文件条目都含作者 comment 和自定义 extra 字段，ZIP 本身也含作者 comment；解压工具可能不恢复这些元数据，因此压缩包内另有 AUTHORSHIP.json，以相对路径、作者与 SHA-256 对应每个文件。

解压到 NTFS 后，可以右键“使用 PowerShell 运行”根目录 Apply-AuthorMetadata.ps1，或在 PowerShell 执行 `& './Apply-AuthorMetadata.ps1'` 恢复每个文件的 Author 数据流。插件运行不依赖该脚本或数据流。FAT/exFAT、部分云盘或复制工具不支持 NTFS 数据流时，文档、清单和压缩包条目中的作者记录仍保留。

读取某文件标识：`Get-Content -LiteralPath './CameraRefinement.uplugin' -Stream Author`。计算主体校验：`Get-FileHash -Algorithm SHA256 './CameraRefinement.uplugin'`，与清单相应记录比较。清单自身不保存自身哈希，避免循环依赖；它自身包含作者字段。

这些是作者署名与完整性记录，不是数字签名、加密保护或不可删除的版权保护。SHA-256 不证明作者身份。发行包没有附加会限制使用的授权条款。
