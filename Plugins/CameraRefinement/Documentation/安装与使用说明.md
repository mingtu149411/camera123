# 安装与使用说明

作者：南京大学24届沈逸文  
版本：0.2.1；二进制环境：UE 5.7.4 / Windows x64。

## 安装

1. 关闭目标工程编辑器。解压 ZIP，将完整的 CameraRefinement 文件夹复制到 `<工程>/Plugins/`。最终应存在 `<工程>/Plugins/CameraRefinement/CameraRefinement.uplugin`，避免多套同名目录。
2. 重新打开工程，在“编辑 → 插件”搜索 Camera Refinement 并启用，按提示重启。
3. 使用 D3D12。当前正式验证配置为 SM5；SM6、TSR、XR 等不能直接视为已验证。
4. 不需要 UE5AI、不需要导入演示关卡，也不需要给场景物体添加脚本。

升级时完整替换旧插件，不要混用旧版 Source、Binaries、Intermediate。其他 UE 版本需用相应引擎和 C++ 工具链重新编译，或通过 RunUAT BuildPlugin 生成发行包。EngineVersion=5.7.0 表示该引擎的兼容版本，实际构建版本为 5.7.4。

## 默认相机和放置相机

顶部播放工具栏“默认相机细化”控制自由视口、默认玩家相机和没有本地覆盖的相机，不要求默认相机出现在 Outliner 中。同一设置位于“项目设置 → 插件 → Camera Refinement / 相机细化”。外部默认初始关闭，按工程保存。

选择 CameraActor 或 CameraComponent，在“相机细化”分类切换“细化”。“跟随默认”移除本地覆盖。优先级：相机显式设置 > 外部默认开关 > 初始关闭。单独关闭的相机不会被默认开关强制开启。

蓝图 API 为 Camera Refinement 下的 SetRefinementEnabled(Camera, Enabled) 和 IsRefinementEnabled(Camera)。本地设置保存在相机附加数据中。

## 官方后处理体积

保持项目设置中的“官方后处理体积细化”开启，再开启当前相机或外部默认细化。已有 PostProcessVolume 自动读取，不需要填写体积引用、添加控制 Actor 或更换材质。

观察清晰分界时，启用体积，关闭 Infinite Extent / Unbound，令 BlendWeight>0，并设置可见的颜色或白平衡覆盖。BlendRadius=0 为硬边界。以斜角让近裁剪面穿过边界并缓慢移动相机；只有该平面同时位于边界两侧时才应出现屏幕分区。边界与近裁剪面平行时整屏切换可能是正确结果。

BlendRadius>0 为平滑区，当前采用原生画面输出插值，不等同于所有原生参数逐像素精确混合。Unbound 体积保留在全局参数栈中，本身没有空间边界。

悬停外部开关可查看最近视图状态和额外场景渲染次数。“原生回退”表示保留引擎默认输出，应检查配置数预算、凸包预算、渲染路径及附近第三方体积接口。

## 自定义材质

在内容浏览器启用“显示插件内容”，找到 CameraRefinement/Materials/MF_RefinedCameraPosition。在材质图调用它，用第一个 WorldPosition 输出替换需要细化的 CameraPositionWS 输入。插件不全局改写引擎该节点；自定义材质直接读取 CameraPositionWS 的逻辑仍需自行接入。

坐标是像素中心在近裁剪面上的世界位置，不是可见物体表面位置，不需要再乘场景深度。第二个输出为相对原生相机位置的偏移。

## 成本和边界

同时跨越 1 / 2 / 3 个体积时，最坏增加 1 / 3 / 7 次完整场景渲染，加一次合成。默认最多 8 个配置，即最多 3 个跨界体积。无需分区时不增加捕获；整面跨界可以直接修正主视图。

几何上限为 256 平面、32 凸包、512 边，超预算回退。XR、低于 SM5、路径追踪和邻近无可读凸包的第三方体积接口未适配。时间抗锯齿、自动曝光历史、景深及跨区模糊可能与独立原生画面合成存在差异，应在目标工程画质下评估。这不是移动端低成本后处理方案。

## 项目打包与卸载

保留 Content、Shaders、Binaries、Source 和 Intermediate。发行包中的 Intermediate 包含 Development/Shipping 必需预编译对象与清单，不能当普通缓存删除。插件函数由正常资产依赖进入 Cook；纯字符串动态加载时应自行配置 Cook 依赖。

卸载前断开项目材质对插件函数的引用，关闭编辑器，移除插件目录和工程插件启用项。相机数据和默认设置保存在工程资产与配置中。正式项目建议使用版本控制。
