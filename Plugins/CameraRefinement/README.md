# Camera Refinement 0.2.1

作者：南京大学24届沈逸文

提供近裁剪平面像素世界位置，以及官方 PostProcessVolume 的逐像素边界分区。无需给背景物体换材质或放置插件控制 Actor。

- [安装与使用说明](Documentation/安装与使用说明.md)
- [技术说明](Documentation/技术说明.md)
- [作者标识与文件完整性](Documentation/作者标识与文件完整性.md)

二进制面向 Windows x64、UE 5.7.4；原生体积功能的验证环境是 D3D12 / SM5。其他引擎版本需重新构建。发行包仅含插件、必要预编译产物和说明，不含测试工程、测试代码、测试报告、AI 桥接插件或演示场景。
